# Security Policy (Medley Fork)

This policy applies to **[ImL1s/medley](https://github.com/ImL1s/medley)** only.
It does not use xAI's HackerOne program.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository:

<https://github.com/ImL1s/medley/security/advisories/new>

If private reporting is unavailable in your environment, open an issue at
<https://github.com/ImL1s/medley/issues> with minimal details and request a
private follow-up channel.

## What to include

- affected version / commit
- platform and install path (source build or release install)
- reproduction steps
- expected vs actual behavior
- impact assessment

Do **not** include real credentials, tokens, or secrets in reports.
